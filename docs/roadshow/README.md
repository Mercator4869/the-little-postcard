## 页面

1. 项目名称 + 一句话 slogan
2. 背景与痛点：一个普通的傍晚，故事开场
3. 核心设计：一张明信片到底装了什么（正面照片 / 背面话与署名 / 邮票是一首歌）
4. 基于明信片的核心功能：看见、听见、留下
5. 完整流程：寄一张 / 穿过星光 / 星空的回信 / 翻到背面 / 留在星空
6. 一个演示案例：火烧云照片 + “好美的火烧云呀” → 明信片与《火烧云》
7. 技术实现与边界：Demo 的局限，以及可拓展性
8. 致谢：黑客松、评委、参赛者与每一个抬头的人

## 修改 P6 演示案例

- 左侧照片使用 `Hackathon/火烧云.jpg`，已压缩为 `assets/fire_cloud.jpg`。
- 配文为“好美的火烧云呀”，署名留空。
- 右侧输出歌曲为《火烧云》，回信内容与署名可直接修改。
- 换案例时，替换左侧图片和配文，再同步修改右侧歌曲名。

## 修改 P5 流程

五个画面现在是现场录屏 GIF，放映时会自动播放：
`上传 → 加载 → 结果 → 翻面听歌 → 留在星空`。PDF 和预览图只显示第一帧。
如需替换，可右键「更改图片」换为同尺寸 GIF。
